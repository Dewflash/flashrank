FlashRank Install Notes
=======================

This release packages FlashRank as a local Next.js web app bundle.
It is not a notarized native macOS app yet; it runs locally in your browser.

What's included
---------------
- app/                 FlashRank source package
- FlashRank.command    Convenience launcher for macOS
- INSTALL.txt          These instructions

Requirements
------------
- macOS
- Node.js 20 or newer
- npm
- Internet access on first run to install dependencies

Install / Run
-------------
1. Open the extracted FlashRank folder.
2. Double-click FlashRank.command.
3. If macOS blocks it, right-click FlashRank.command and choose Open.
4. The first run installs dependencies, builds the app, opens your browser,
   and starts FlashRank at http://localhost:3333.

Manual run
----------
If you prefer Terminal:

  cd app
  npm install
  npm run build
  PORT=3333 npm run start

Then open:

  http://localhost:3333

API keys
--------
FlashRank can run with public App Store data without private keys.
For optional private integrations, copy .env.local.example to .env.local
inside app/ and fill in the relevant values.

Notes
-----
- Keep the Terminal window open while using the app.
- To stop FlashRank, press Control-C in the Terminal window.
- If port 3333 is already in use, set a different port manually:

  PORT=3334 npm run start
